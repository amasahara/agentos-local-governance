# AgentOS v0.23.1 Developer Guide

Build a fresh canonical Context Pack, inspect the selected hash-pinned model profile, and compile with `--budget-mode adaptive` (default) or `fixed`. Control Plane content is always allocated first and is never truncated. Numeric runtime token observations may be recorded locally to increase future output/safety reservations, but prompt/response content is not stored. AgentOS does not switch providers/models and MCP cannot mutate profiles, budgets, or observations.
