AgentOS Local Governance v0.23.3 Windows Portability Hotfix 1

Apply from the AgentOS repository root with one command after placing the updater under tools/:

  python tools\apply_v0233_windows_hotfix.py . --run-tests

The updater:
- requires VERSION 0.23.3;
- is idempotent and fail-closed;
- backs up modified files under .agents/runtime/hotfix-backups/;
- preserves CRLF/LF style;
- compiles all patched Python files;
- with --run-tests, automatically sets PYTHONPATH and runs the seven focused suites.
