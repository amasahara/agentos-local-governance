# AgentOS Local Governance


## v0.7.0 — Code Intelligence & Documentation Governance

AgentOS v0.7.0 adds local-first guarded tool execution, egress auditing, file-read caching, an incremental Python symbol index, and enforceable source documentation contracts.

AgentOS v0.7.0 bổ sung guard bắt buộc cho tool, audit egress, cache đọc file, Python symbol index tăng dần và contract tài liệu mã nguồn có enforcement.

- Path: once in the file header.
- Module purpose: in the file header.
- Class/function contract: in the symbol's own docstring.
- Public functions/methods: document all meaningful inputs and returned outputs.
